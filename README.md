# org

> **This project is no longer being developed.** It has been superseded by [**gro**](https://github.com/tjamescouch/gro) (`@tjamescouch/gro` on npm), which builds on the same ideas with a more capable runtime, streaming architecture, and agent-to-agent communication via [AgentChat](https://github.com/tjamescouch/agentchat).

---

_org was an agentic dev helper that could "do things" in your repo while you watched, reviewed, and approved every change._

The original vision — AI teammates you can trust, understand, and control — lives on in gro. If you're here looking for an LLM agent runtime, head to [gro](https://github.com/tjamescouch/gro).
